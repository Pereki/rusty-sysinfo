# rusty-sysinfo

A lightweight Rust project for gathering and displaying system information.

> **Status:** Early development  
> **Primary language:** Rust (100%)

## ✨ Features

- Inspect basic system information (OS, CPU, memory, etc.)
- Simple, fast, and minimal Rust implementation
- Easy to extend with additional metrics

## 📦 Installation

### Prerequisites

- [Rust](https://www.rust-lang.org/tools/install) (latest stable recommended)
- Cargo (included with Rust)

### Clone the repository

```bash
git clone https://github.com/Pereki/rusty-sysinfo.git
cd rusty-sysinfo
```

## 🚀 Usage

Run in development mode:

```bash
cargo run
```

Build release binary:

```bash
cargo build --release
```

Run tests:

```bash
cargo test
```
